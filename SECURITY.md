# Security Policy

This personal GitHub Skills repository contains a fictional school application from the upstream MIT-licensed exercise. It is not a production service and must not contain real student information, employer data or credentials.

## Report a vulnerability privately

Do not publish exploitable details in an issue or pull request. Open this repository's Security tab and select Report a vulnerability to send a private advisory to me, the repository maintainer.

Include a concise description, affected files, minimal reproduction steps using fictional data, potential impact and any suggested fix. Remove tokens, passwords and personal information from attachments.

I will review reports as capacity allows. I do not promise a response deadline, financial reward or production support. Do not test systems that you do not own or have permission to assess.

## Maintenance

The default branch is the maintained exercise version. Dependabot alerts and security updates, grouped security updates, weekly pip version updates, CodeQL default setup and secret push protection are configured for this public repository. Automated findings require review and do not prove the application is secure.
